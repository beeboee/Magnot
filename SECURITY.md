# Security policy

Please report security-sensitive issues privately through GitHub's security advisory reporting for this repository. Do not include exploit details in a public issue before a fix is available.

Magnot 1.2.x for Minecraft 1.21.1 / NeoForge is the current supported release line.

Active version-parity branches may receive fixes while they are maintained. Older alpha files, abandoned snapshots, and unmaintained legacy branches are not guaranteed security updates. Supported version status is tracked in [docs/VERSION_SUPPORT.md](docs/VERSION_SUPPORT.md).
