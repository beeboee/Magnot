# Magnot 1.2.0

Magnot 1.2.0 is the first release where Create is optional. It keeps the existing ferrous-region gameplay while separating Magnot's authoritative logic from optional presentation and compatibility layers.

## Release target

- Minecraft 1.21.1
- NeoForge 21.1.230+
- Java 21
- Create 6.0.10–6.0.x when installed

Create, Sable, JEI, EMI, and supported magnet/vacuum mods are optional.

## Selection architecture

`FerrousSelectionRuntime` is the single client event owner for tube selection, target highlighting, stored-region outlines, removal input, and placement previews. It selects exactly one backend:

- `CreateFerrousSelectionBackend` when Create is installed
- `NativeFerrousSelectionBackend` otherwise

Both consume the same Magnot region data, limits, ownership rules, networking, durability, and removal behavior. The two backends never process or render the same selection simultaneously.

### Create-backed path

The optional Create path reuses Create/Catnip raycasting, Outliner rendering, fade behavior, line emphasis, glue-style sounds, and the Sable/Create outline bridge where available. Magnot supplies its own ferrous face texture and does not create Create glue entities or use Create placement packets.

### Native path

The native renderer provides the same Magnot interaction without Create:

- immediate selection and placement previews
- passive stored-region outlines
- textured highlighted faces using Magnot artwork
- thick highlighted borders rendered as geometry rather than unreliable platform line widths
- outside one-way face visibility and complete inside visibility
- quick fade from selected back to passive while selection itself remains immediate
- inward/outward face offsets that avoid z-fighting and floor occlusion
- transformed oriented boxes for Sable sublevels
- vanilla slime sounds when Create is absent

Manual in-game testing confirmed expected behavior with and without Create, including the final native visual parity pass.

## Adaptive materials and recipes

`AdaptiveMaterials` is the shared material-availability authority used by recipe conditions, creative-tab visibility, JEI, and EMI.

| Material state | Active paste path | Magnot dust |
|---|---|---|
| External `c:dusts/iron` | external dust recipe | hidden and unobtainable |
| No external dust + Create | Create crushing and Magnot dust recipe | visible and required |
| No external dust + no Create | eight iron nuggets plus slime adhesive | hidden and unobtainable |

| Plate state | Active tube path |
|---|---|
| `c:plates/iron` populated | common-tag plate or sheet |
| `c:plates/iron` empty | iron ingot fallback |

Inactive recipes are rejected before entering the recipe manager. Dormant fallback dust is omitted from the creative tab and hidden from JEI and EMI.

## Optional dependency safety

Direct optional-API imports are isolated in compatibility packages. The published jar does not require Create, Ponder, Flywheel, Registrate, Sable, JEI, EMI, or any supported magnet mod to launch.

Development runtimes are selected explicitly with Gradle properties and use separate clean and compatibility game directories.

## Version-parity policy

Create availability no longer determines whether Magnot can be ported. Every new target starts from the native backend and core region rules. Create-backed rendering is added only where a compatible Create release exists.

The active port order and definition of parity are maintained in [VERSION_SUPPORT.md](VERSION_SUPPORT.md).
