# Magnot — Forge 1.16.5 alpha

Java 8 implementation of Magnot 1.2's complete loader-independent core: stable synchronized regions, native textured selection rendering and fade, immediate preview, validated ray removal, indexed/cached path blocking, API semantics, and adaptive dust/plate recipes with Create and vanilla fallbacks.

## Optional compatibility adapters

Active adapters target:

- Simple Magnets
- Item Collectors
- Modular Routers Vacuum Module
- Mekanism Magnetic Attraction Unit
- Draconic Evolution magnets
- Reliquary Fortune Coin
- Industrial Foregoing Infinity Backpack

Mob Grinding Utils and Sophisticated Core are not registered because the selected 1.16.5 ecosystem does not provide the copied targets. Sable remains separate.
